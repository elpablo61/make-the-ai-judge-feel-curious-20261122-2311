Entry for the [make.fun bounty "Make the AI judge feel curious"](https://make.fun/bounty/make-the-ai-judge-feel-curious-20261122-2311).

`main.ts` (Node 22, stdlib only) writes one short text — 1 to 280 characters — to `/output/entry.txt`: a text written to intrigue the AI judge reading it.

Run it with:

```sh
node main.ts
```
